# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-29

### Added

- Sidebar footer badge aggregating per-session pending / running / completed states across workspaces.
- Floating panel listing per-workspace sessions with one-click navigation.
- Collapsed-rail fallback: a single status dot when the sidebar is collapsed.
- Optional upstream seam (`upstream-seam.patch`) for inline folder-row highlighting.
